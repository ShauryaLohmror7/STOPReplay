# Channel marks

Full-color SVG marks for WhatsApp, Signal, Telegram, Slack, Discord, LinkedIn and X are from [SVG Logos via Iconify](https://github.com/gilbarbara/logos), pinned to `@iconify-json/logos@1.2.20`. X uses the white variant for the dark surface. SVG fill colors are preserved; the UI does not tint or desaturate these marks.

Official app artwork downloaded from the Apple App Store:

- [Instagram](https://apps.apple.com/us/app/instagram/id389801252?uo=4): `instagram.png`.
- [Messenger](https://apps.apple.com/us/app/messenger/id454638411?uo=4): `messenger.png`.
- [Microsoft Teams](https://apps.apple.com/us/app/microsoft-teams/id1113153706?uo=4): `microsoftteams.png`.
- [Messages](https://apps.apple.com/us/app/messages/id1146560473?uo=4): `imessage.png`.

Generic channels (email, SMS, calendar, document, calls, MFA and live chat) keep the Lucide symbols because those channel types do not identify a specific provider. Logos identify simulated challenge channels, not live service integrations. Connecting beams remain signature cyan.
